# Respir

Application Android de rappel horaire : **cette heure, tu ne fumes pas.**

Pensée pour **Samsung Galaxy Z Fold** et **One UI 8**.

## Télécharger l'APK

Va dans [Releases](https://github.com/Mixbox2007/respir-apk/releases) et télécharge `Respir-1.0.0.apk`.

1. Ouvre le fichier sur le Fold.
2. Autorise l'installation depuis des sources inconnues si Android le demande.
3. Ouvre **Respir** → **Activer chaque heure** → accepte les notifications.
4. Réglages → Applications → Respir → **Batterie → Non restreint** (indispensable sur One UI).

## Fonctions

- Alarme exacte toutes les 60 minutes (AlarmManager)
- Notification française
- Reprise après redémarrage
- Compteur d'heures sans cigarette, envies tenues, glissades
- Écran redimensionnable (couverture + écran interne)

L'APK de release est signé avec la clé debug CI — installation manuelle, pas Play Store.
